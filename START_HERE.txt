QueuePact — our next GenLayer project

What it does: routes a community request to the team responsible for it, then
allows only that team's wallet to acknowledge receipt and responsibility.

Example: changing an event time on a notice goes to PROGRAMME. Rearranging chairs
goes to VENUE. Requests needing both teams stay unassigned for review.

This is a separate project from SurplusHold. It manages task responsibility,
not stock. ExplainGate remains submitted and its walkthrough remains finished.
SurplusHold's walkthrough and GitHub upload are complete; its final submission
has not been explicitly confirmed in this conversation.

Status: local prototype; no hosted deployment or submission yet.

First phone step:
Download queuepact.py, open https://studio.genlayer.com/ and use Add From File.
Send a screenshot of its deployment form. We will fill the ONE constructor field

Planned live work: ONE deployment and FOUR writes (three tickets, one acknowledgement),

No extra live test suite is planned after these steps pass.
